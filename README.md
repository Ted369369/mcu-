# MCU 補課指南：蜘蛛人4 Brand New Day

為**完全沒接觸過漫威**的新手做的補課網站。一次補完《蜘蛛人4：Brand New Day》(2026/7/31) 之前的所有劇情與世界觀。

> 線上版：<https://ted369369.github.io/mcu-/>

---

## 網站有什麼

| 頁面 | 內容 |
| --- | --- |
| **首頁** | TL;DR 三句話結論、Key Findings 重點速覽、最短路徑（5 部）、《蜘蛛人4》焦點 |
| **時間線** | 49 部作品，可切換「上映順序 / 劇情年代」，可依分類篩選，每部都能點開看完整劇情 |
| **角色** | 69 位角色，每一位都有**個人時間線** —— 在哪一部發生了什麼事 |
| **核心概念** | 11 個關鍵名詞、六顆無限寶石的來歷與最終命運、15 個組織與勢力 |
| **蜘蛛人4** | 官方大綱、製作資訊、完整卡司、與《末日之戰》的關聯 |
| **觀影指南** | 方案 A（5 部必看）、方案 B（觀影順序比較）、影集取捨、分階段行動、注意事項 |

### 兩種理解劇情的方式

1. **照時間線讀** —— 從 2002 年的舊蜘蛛人電影一路到 2027 年的《秘密戰爭》。
2. **挑一個角色跟** —— 點任一角色，會看到他／她在每一部作品裡發生的事，串成一條個人故事線。

作品與角色之間**互相連結**：看電影詳情時可以跳到登場角色，看角色時可以跳回作品。

## 技術

純靜態網站，**零依賴、零外部請求**：

```
index.html                    # 單頁應用外殼
assets/css/style.css          # 設計系統
assets/js/data-timeline.js    # 49 部作品資料
assets/js/data-characters.js  # 69 位角色資料
assets/js/data-extra.js       # 概念、寶石、蜘蛛人4 檔案、觀影指南
assets/js/art.js              # 原創 SVG 美術系統（圖徽 + 海報生成）
assets/js/app.js              # hash 路由 SPA + 搜尋
```

- 沒有 build step、沒有 npm、沒有框架 —— 直接打開 `index.html` 就能跑
- 沒有 CDN、沒有外部字體、沒有外部圖片 —— 離線可用
- 響應式（手機／平板／桌機）、支援鍵盤操作（`/` 聚焦搜尋、`Esc` 關閉）
- 深層連結可分享，例如 `#/e/no-way-home`、`#/c/peter-parker`

### 關於圖片

站內**所有圖像都是本站自繪的原創 SVG 向量圖形**（`assets/js/art.js` 裡的 41 個圖徽，加上程式生成的漸層海報與寶石）。

刻意不使用電影劇照或預告截圖 —— 那些是有版權的素材，放進一個公開網站並不妥當。改用原創圖形的好處是：網站完全自足、離線可用、載入極快、不會有圖片失效或版權問題。

## 本機預覽

```bash
python -m http.server 8000
```

然後開 <http://localhost:8000>。（直接雙擊 `index.html` 也可以。）

## 要改內容

劇情文字全部集中在 `assets/js/data-*.js`，改完存檔重新整理就好，不需要編譯。

改了 CSS 或 JS 之後，把 `index.html` 裡的 `?v=1` 往上加（`?v=2`…），別人的瀏覽器才會拿到新版而不是快取。

## 資料來源與可信度

內容整理自《Spider-Man Brand New Day: Complete MCU Catch-Up Guide for Newcomers》，該指南引用 Marvel.com 官方大綱、Deadline、Variety、The Hollywood Reporter 等來源。

⚠️ **請注意：**

- 2008–2024 年的作品劇情為已上映的確定內容。
- **2025–2026 年的作品**（《美國隊長4》《雷霆特攻隊＊》《驚奇4超人》《末日之戰》《蜘蛛人4》）多來自預告、首波媒體評論與片商釋出的官方大綱，屬上映前後的早期資訊，最終請以正片為準。
- **Sadie Sink 在《蜘蛛人4》的角色身分尚未經官方證實** —— 網路上關於琴葛雷／關史黛西／蜘蛛格溫的說法都是未經證實的傳聞。
- **征服者康（Kang）已不是主線大魔王**，已改由末日博士接棒。任何把康當成《末日之戰》反派的資料都已過時。
- 譯名採台灣通用譯法；部分角色（The Leader 智謀者、Sentry 哨兵、Tombstone 墓碑）官方譯名可能略有差異。

站內「觀影指南」頁面末尾有完整的注意事項說明。
